Truco Ladrão!
-
This is a game made by me and 2 friends inspired by the brazilian card game: Truco! And by the game Balatro

Made in Godot, this is a 2D fun project that consist of Truco but you have powers like: Increase the value of your card, decrease the value of a bot's card, change cards with the bot or reveal a bot's card.

This version (12th commit) has a lot of placeholders sprites and GUI elements, also some unfinished parts, but the core game is funcional.


For future reference and updates:
-
- The bot doesn't think, it plays the cards in order
